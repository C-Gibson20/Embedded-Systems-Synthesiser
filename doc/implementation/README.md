# Real-Time Music Synthesiser Implementation

This section documents the implementation of the real-time music synthesiser. While the report focuses on system design and real-time analysis, the documentation in this directory describes the structure of the source code, the responsibilities of each module and implementation-specific details.

The implementation is organised into a set of subsystems:

- Audio synthesis: Waveform generation and voice management.
- Input handling: Keyboard matrix and rotary encoder processing.
- Networking: CAN protocol communication.
- User interface: OLED display and UI logic.
- System configuration: Runtime configuration and shared state.
